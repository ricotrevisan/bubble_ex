# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue to report a security vulnerability.

Report vulnerabilities privately using GitHub's built-in security advisory flow: navigate to this repository's **Security** tab and click **"Report a vulnerability"**. This opens a private channel between you and the maintainers. You will receive an acknowledgement and a follow-up within a reasonable timeframe.

## Responsible Use

BubbleEx is a dual-use analysis tool. It can enumerate database structures, surface exposed endpoints, and scan for secrets in Bubble.io applications.

**Use BubbleEx only on applications you own or are explicitly authorized to test.** Do not use it to access, collect, or exfiltrate data from applications you are not authorized to analyze. Unauthorized use may violate computer fraud and abuse laws in your jurisdiction.
